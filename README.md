# Projeto TCC - TranquilEase

Este é um aplicativo móvel desenvolvido para auxiliar pessoas que enfrentam dificuldades emocionais. O projeto foi desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) de um amigo e tem como objetivo proporcionar suporte emocional através de diversas funcionalidades que ajudam a melhorar o bem-estar mental.

## Descrição do Aplicativo

O aplicativo oferece um espaço seguro e acolhedor para que os usuários possam lidar com suas emoções de forma saudável e produtiva. As principais funcionalidades incluem:

- **Seções de Desabafo de Emoções**: Os usuários podem registrar suas emoções e reflexões, ajudando a organizar seus pensamentos e a se expressar de maneira mais aberta.
  
- **Desabafos em Si**: Um espaço dedicado para o usuário se abrir e desabafar, refletindo sobre seus sentimentos de forma privada e sem julgamentos.

- **Conversa com IA (API do Chat GPT)**: O aplicativo integra uma inteligência artificial baseada na API do Chat GPT, proporcionando uma conversa interativa e reconfortante, onde o usuário pode discutir suas emoções ou simplesmente ter uma conversa amigável.

- **Seções de Meditação, Yoga e Respiração**: O app oferece orientações práticas para meditações guiadas, yoga e técnicas de respiração, todas com o objetivo de proporcionar momentos de relaxamento e alívio do estresse.

Este aplicativo foi projetado para ajudar na gestão emocional, proporcionando aos usuários uma combinação de ferramentas que podem ser usadas no dia a dia para melhorar a saúde mental e emocional.

## Funcionalidades

- Registro de emoções e sentimentos através de desabafos.
- Conversa interativa com uma IA para suporte emocional.
- Instruções de meditação e yoga para ajudar na redução do estresse.
- Técnicas de respiração para acalmar e relaxar.

## Banco de Dados

Atualmente, o banco de dados utilizado no projeto está desativado. O banco de dados é fornecido de forma gratuita pelo Supabase, e devido a isso, ele é automaticamente desativado após um período de inatividade. Caso você esteja rodando o aplicativo localmente e precise que o banco de dados esteja ativo, será necessário ativá-lo manualmente no painel do Supabase.

## Tecnologias Utilizadas

O aplicativo foi desenvolvido utilizando as seguintes tecnologias:

- **C#**: Linguagem de programação utilizada para o desenvolvimento do aplicativo.
- **.NET MAUI**: Framework utilizado para criar aplicativos móveis multiplataforma, permitindo que o app seja executado tanto em dispositivos Android quanto iOS.
- **API do Chat GPT**: Integração com a API do Chat GPT para proporcionar uma experiência interativa de conversação com a IA.
- **Supabase**: Banco de dados gratuito online utilizado para armazenar os dados do usuário de forma segura e eficiente.

## Como Rodar o Projeto

Para rodar o aplicativo em seu ambiente local, siga os seguintes passos:

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/MiiKel36/TranquilEase.git
   ```

2. **Instale as dependências**:
   Certifique-se de ter o .NET MAUI instalado em seu ambiente de desenvolvimento. Você pode obter instruções completas de instalação [aqui](https://docs.microsoft.com/pt-br/dotnet/maui/).

3. **Abra o projeto no Visual Studio** e selecione a plataforma de sua preferência (Android ou iOS).

4. **Execute o aplicativo** no emulador ou em um dispositivo real.
